# Vocab — 20.08.2026 (KB 108–109, AB 123–128)

---

## Genitiv — артикли / Artikel

| | Nominativ | Genitiv |
|---|---|---|
| Mask. | **der** Doktor | **des** Doktors |
| Fem. | **die** Familie | **der** Familie |
| Neutr. | **das** Hotel | **des** Hotels |
| Pl. | **die** Banken | **der** Banken |

- Mask./Neutr. → существительное получает окончание **-(e)s**
- Fem./Pl. → существительное не меняется
- Неопределённый артикль: **eines** Doktors / **einer** Familie / **eines** Hotels
- Pl. без артикля → **von** + Dat: Kredite **von** Banken

---

## Предлоги с временным значением / Präpositionen temporal

- **vor** + Dat — назад (vor drei Jahren — три года назад)
- **nach** + Dat — после (nach dem Abitur — после абитура)
- **von ... bis** — с ... до (von 2005 bis 2007)
- **zwischen** + Dat — между (zwischen Januar und Juni)
- **seit** + Dat — с ... (и до сих пор) (seit dem 1. Juli)
- **in** + Dat — через (in einem Jahr — через год)

---

## Новые глаголы с предлогами / Neue Verben mit Präpositionen

*+ Akkusativ:*
- sich erinnern an + Akk — вспоминать о *(возвр.)*
- sich bedanken für + Akk — благодарить за *(возвр.)*
- sich entscheiden für + Akk — решать в пользу / выбирать *(возвр.)*
- bitten um + Akk — просить о (nicht reflexiv)
- stolz sein auf + Akk — гордиться чем-то

*+ Dativ:*
- passen zu + Dat — подходить к/для
